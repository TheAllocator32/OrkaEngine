## SceneNodes
The 3D view consists of multiple objects called **SceneNodes**. Orka's SceneNode may be a ModelSceneNode, a LightSceneNode whatever. Everything visible (and invisible) that has a transform (position/rotation + maybe scale) is a SceneNode. Every SceneNode may own a **Script** that is able to define custom behavior outside the C++ code (See [README](../../README.md)/Scripting Philosophy).

### SceneNode base class
Contains all base functions inherited to the specific SceneNodes.

#### Important member functions
The following functions also apply to all SceneNodes inheriting from this SceneNode base class (so as for now: all of them) 
- `SceneNode& create()` (static) 
	Creates a new SceneNode owned by the SceneManager. This allows returning a safe-to-use (almost idiot proof) reference to it
- `void destroy()`
	Immediately invalidates the SceneNode, removes it from physics (if ModelSceneNode) and destroys it at the end of the frame. Calling destroy will **not** immediately destroy the entire object so pointers and references stay "physically" valid until the next frame

- `void setPosition(vector3df position/float x, float y, float z)`
	Sets the position of the node (supports vector3d primitive or 3 floats)
- `void setScale(vector3df scale/float x, float y, float z)`
	Sets the scale of the node (supports vector3d primitive or 3 floats)
- `void setRotation(quaternion rotation/float w, float x, float y, float z)`
	Sets the rotation of the node (supports quaternion primitive or 4 floats)

- `void setVisible(bool visible)`
	Sets the visibility. Note (for ModelSceneNode): Visibility doesn't change physics behaviour, so the object still collides (trust me this looks strange and buggy)

- `vector3df getCenterPoint()`
	Returns the world-space center point (in case of non ModelSceneNodes this returns the position)
- `SceneNodeType getType()`
	Returns the type of the SceneNode. Can be used to check the type before performing casts (such as static_cast) or just to check if you are handling a camera or a light etc.

- `T& as()`
  Use this to cast SceneNodes. Example `ModelSceneNode&  m = otherNode.as<ModelSceneNode>();`

- `void setCustomUserData(std::string tag)`
	Stores a custom string in the node, for example to group objects.
- `void setCustomUserWhaleMLFile(const WhaleMLFile& file)`  
	Stores custom structured data in the node as a WhaleML object.

##### Example
```c++
SceneNode& node = SceneNode::create();
node.setCustomUserData("test");
node.setPosition(1,2,3);
// ...
node.destroy();
```

SceneNodes are non-copyable and non-movable. Store the Identifier to access the node later, but avoid keeping a pointer to the reference (which would introduce dangling pointers etc.). That said: Do not try to copy the node by value.

#### Scripting
Every **SceneNode** may own a **Script** that should implement the following 3 functions

<details>
<summary><strong>Lua Example</strong></summary>

```lua
function create(self)
    -- Called on creation
end

function update(self, delta)
    -- Called every frame
end

function destroy(self)
    -- Called before destruction
end
```

</details> 
<details> <summary><strong>AngelScript Example</strong></summary>

```c++
void create(SceneNode@ self) {
    // Called on creation
}

void update(SceneNode@ self, float delta) {
    // Called every frame
}

void destroy(SceneNode@ self) {
    // Called before destruction
}
```
</details>

The callback parameter may use the most specific exposed SceneNode type.
For example, a script attached to a `ModelSceneNode` may use `ModelSceneNode` instead of `SceneNode`.
Generic scripts that are shared across different SceneNode types should keep using `SceneNode`.

<details> <summary><strong>AngelScript ModelSceneNode Example</strong></summary>

```c++
void create(ModelSceneNode@ self) {
    
}

void update(ModelSceneNode@ self, float delta) {
    
}

void destroy(ModelSceneNode@ self) {
    
}
```
</details>

> **ℹ️ NOTE**  
> Since every SceneNode **OWNS** its script instance, you may define `local` variables outside the functions and they won't collide with other SceneNodes using the same **script file**.
> To override this set *script.instance : false* in the SceneNode's WhaleML file
> File-loading calls made from a SceneNode script resolve relative paths relative to the script file itself.

### ModelSceneNode
A SceneNode owning a 3D Model.

#### Important member functions
- `void loadFile(std::string_view path)`
	Loads the SceneNode by parsing a *.model.whaleml* file
- `void loadGLB(std::string_view path)`
	Loads a raw GLB file directly (not recommended for production, intended for quick tests)

#### Example
```c++
ModelSceneNode& sceneNode = ModelSceneNode::create();
sceneNode.loadFile("thesacredrock.model.whaleml");
// ...
```

#### Script note
- A model-specific script may declare `create/update/destroy(ModelSceneNode@ self, ...)`
- A shared script should keep declaring `create/update/destroy(SceneNode@ self, ...)`
- When a script calls `loadFile("...")` or `loadGLB("...")`, relative paths are resolved relative to that script file

For an example `.model.whaleml` read [FileFormats.md](FileFormats.md)

## SceneManager
The SceneManager manages lifetimes of the SceneNodes and Scenes. It is a static subsystem: it has one global state and is not instanced.

### Important member functions
All members are obviously static. `create` and `clear` are automatically called by `OrkaEngine::init/deinit
- `SceneNode& getSceneNode(Identifier id)`
  I know this function is self explaining but very very important because this is the only way to convert IDs to SceneNodes! Throws if SceneNode does not exist.
- `bool sceneNodeExists(Identifier id)`
  Also very important. Check this before using `getSceneNode` if you are unsure if it still exists. Also returns false if the SceneNode will be destroyed at the end of the frame!
  
> ^ Those 2 functions also exist for `Scene` (`getScene` and `sceneExists`) ^

- `std::vector<Identifier> getAllSceneNodes()`
  Returns the IDs of all currently registered SceneNodes

- `std::vector<Identifier> getSceneNodesWhere(const std::function<bool(const SceneNode&)> predicate)`
  Returns all SceneNodes where `predicate` returns *true*. Predicate should look like:
  `[](const SceneNode& node) { return node.getName() == "Player"; }`

#### Examples
Convert ID into specific SceneNode:
```c++
Identifier nodeID = ...; // Any ID
ModelSceneNode& node = SceneManager::getSceneNode(nodeID).as<ModelSceneNode>();
```
Find the 2 nodes with the name "Ball" and convert them to ModelSceneNodes:
```c++
std::vector<Identifier> balls = SceneManager::getSceneNodesWhere([](const SceneNode& node) { return node.getName() == "Ball" });
ModelSceneNode& ball1 = SceneManager::getSceneNode(balls[0]).as<ModelSceneNode>();
ModelSceneNode& ball2 = SceneManager::getSceneNode(balls[1]).as<ModelSceneNode>();
```
Find all nodes with Y-position below -10:
```c++
std::vector<Identifier> nodes = SceneManager::getSceneNodesWhere([](const SceneNode& node) { return node.getPosition().y < -10; });
```
To filter by criteria specific to a `SceneNode` subclass, cast the node to the desired type:
```c++
std::vector<Identifier> nodes = SceneManager::getSceneNodesWhere([](const SceneNode& node) { if(node.getType() == SNT_MODEL) return node.as<ModelSceneNode>().getBS().getRadius() < 10; return false; });
```
